Tile caption styles — proposals

The plain bold-text caption under each tile reads flat next to the colored glyphs above it. Six alternatives, using the same sample tiles (two trailer layouts + Advanced Multi-Voltage, one shown selected) so you can compare directly against real content.

A · Baseline current

Plain bold 12px ink text, centered. Flat next to the colored art.

B · Eyebrow, uppercase

Small tracked-out uppercase label with a tiny ZF-blue dot above it — reads like a spec-sheet tag rather than a button caption.

C · Two-line with subtitle

Bold name plus a smaller muted second line (its group/category). Adds information without extra chrome; degrades gracefully to one line if there's no subtitle.

D · Pill / chip

Caption sits inside a soft light-blue rounded chip instead of bare text — visually pairs the label back to the tile's accent color.

E · Underline accent interactive

Bold text, no visible rule at rest; a ZF-blue underline draws in on hover, and stays filled + text turns blue when that tile is selected — the caption itself reflects state. Hover the cards below.

F · Numbered tag

A tiny monospace index chip before the label — useful if these tiles ever need a stable reference number (e.g. for a parameter sheet or support call).

Recommendation: E for the trailer/function tiles that are actually clickable (the caption then echoes selection, not just the tile) — fall back to B anywhere a caption is purely descriptive, non-interactive.
