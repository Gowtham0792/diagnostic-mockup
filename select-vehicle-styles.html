"Select vehicle" — styling options

Same step (choose trailer kind + axle layout), five visual treatments. All use the same trailer glyphs — drawbar / gooseneck / rigid front connector plus the axle groups. Click tiles to see the selected state. Pick one (or a mix) and I'll apply it to the authoring tool.

A · Outline tiles currently live

Bright cyan line-art in an outlined rounded square. Light, neutral, reads as "technical". Weak selected state unless reinforced (here: ZF-blue border + glow).

B · Soft filled cards

No borders; a tinted fill + soft shadow gives depth. Strong, unmistakable selected state (solid ZF blue, glyph inverts to white). Feels more like a modern product UI, less like a schematic.

C · Category first, then layout

Progressive disclosure: pick the trailer kind, then only that kind's axle layouts appear. Fewer choices on screen at once — best when the list grows or for less-expert users.

D · Compact rows

Glyph + label + plain-language axle description + radio. Densest; scannable; carries text so the picture isn't the only cue. Good on smaller screens and for accessibility.

E · Blueprint (dark)

Dark canvas, glowing cyan glyphs. Distinctive, "engineering workbench" feel — fits an authoring tool aimed at specialists. Higher contrast for the line-art; needs a dark theme throughout the tool to be coherent.

Recommendation: B for the clearest selected state and a modern feel, or C if the trailer list will keep growing. D is the safe, accessible fallback. Mixing is fine — e.g. C's category step wrapping B's tiles.
