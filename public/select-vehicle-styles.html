"Select vehicle" — layout options

Same 11 trailers, five ways to lay them out in less space. All wrap / scroll gracefully — drag the window narrow to check.

Tip: narrow the browser to see wrap behaviour.

L1 · Unified strip recommended

One continuous row of all 11. Each kind is a labelled cluster with a thin divider; on wide screens it's a single line, on narrow it wraps cluster by cluster. ~1/3 the height of the current layout.

L2 · Compact matrix

Kind name in a left column, its layouts in a row beside it. Three tidy rows, no wasted vertical space, labels always visible.

L3 · Horizontal scroll rail

Always a single line; scrolls (or swipes on touch) when it overflows. Axle count captioned under each. Good if the list keeps growing.

L4 · Kind selector, then one row

Pick the kind from a segmented control; only that kind's layouts show — never more than four tiles, always one line. Smallest footprint, costs one extra click.

L5 · Tiny chips with caption

Small borderless-ish glyphs with an axle-count caption, all in one wrapping flow separated by dividers. Densest; the caption carries meaning so the picture can shrink.

Recommendation: L1 (unified strip) for the authoring tool — one line on desktop, clean wrap when minimized, keeps the labels. L2 if you want the kind labels pinned left. L4 if screen space is very tight.
